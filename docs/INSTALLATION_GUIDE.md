# Installation guide

**Phone needed:** Android 8.0 or newer.

1. Copy the APK to the phone (download it, or send it by WhatsApp / USB / Bluetooth).
2. Tap the APK file. Android asks to allow installing from this source: tap **Settings**, switch on **Allow from this source**, go back and tap **Install**.
3. Open **FoodLabel Studio**. Type your business name and tap **Create business**.

**Permissions the app asks for, and when**

| Permission | When | Why |
|---|---|---|
| Nearby devices (Bluetooth) | When you tap Search in Printer Manager | To find and connect to Bluetooth printers |
| Location (Android 11 and older only) | Same | Android requires it for Bluetooth search on old versions |
| USB device access | When you tap Allow on a USB printer | To send data over the OTG cable |

No account, no internet. The app never sends your data anywhere. Network access is used only to reach a Wi-Fi/LAN printer you add.

**Updating:** install the new APK over the old one. Your data stays. Before each schema upgrade the app also keeps a safety copy of its database.

**Moving to another phone:** Settings & Tools › Backup & Restore › Back up all businesses. Copy the ZIP to the new phone, install the app, create any business, then Backup & Restore › Choose backup file › Add as new business.
